uiam 桌面 · 四个界面方案

四套方案的应用清单、窗口内容、交互逻辑完全一致，区别只在外壳：壁纸、导航形态、窗口装饰、明暗。 点缩略图或「打开」进入可交互版本。
A
macOS Tahoe · Liquid Glass 已选
13px 连续圆角、透明标题栏、玻璃 Dock（固定栏 + 临时栏）、24% squircle 图标。桌面是 widget 网格，可拖动排序、换尺寸、增删并持久化；主题三态切换带圆形扩散。
打开
B
Windows 11 风格 居中任务栏
任务栏居中、开始菜单从底部弹出，窗口控制按钮在右上。对国内用户最熟悉，培训成本最低。
打开
C
极简浅色 留白 · 低噪音
浅底细网格、左侧 64px 图标栏、顶部细状态条。信息密度低，长时间盯着不累，更像现代 SaaS 而不是老式后台。
打开
D
深色科技感 暗色 · 发光强调
近黑底 + 青蓝光晕 + 细网格，左侧图标栏带发光指示条。运维和监控场景下更耐看，也更容易做「在线状态」这类实时反馈。
打开
四套方案的共同点（这些是产品逻辑，不随风格变）：
一、网关配置是桌面上的一个普通应用，不是主界面——「操作系统」的语义就是所有能力平等。
二、单点登录窗口里有 home_url，因为 adm 的应用表没有 url 字段，应用入口只能存在 uiam。
三、桌面是 widget 网格而不是图标阵列——时钟、当前用户、在线数、快捷应用、最近发布、网关节点、今日登录、待办审批，每个人可以自己排布并持久化。
四、窗口可拖动、最小化、最大化、关闭，四个方案都实现了。
